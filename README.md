# SpotFinder Frontend

Frontend application for SpotFinder.

Tech stack:

- React
- TypeScript
- Vite
- Axios
- React Router

Backend API:

- Java 21
- Spring Boot
- JWT authentication
- PostgreSQL
- Swagger/OpenAPI

---

# Project status

Current frontend scope:

- Authentication
- JWT token storage
- User profile
- Spots list
- Create new spot
- Admin moderation page

Frontend is currently used as:

- admin panel
- QA/testing UI
- stage frontend
